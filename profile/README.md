## AIPOCH Open-Science

An open-source AI research workbench for **macOS, Windows, and Linux**. Bring papers, data, and a research question into one workspace, then use scientific agents to run analyses and produce results you can review.

*AIPOCH Open-Science research workspace. Interface details may vary by release.*

- **Keep the work together.** Papers, Python and R execution, scientific data connections, and generated files share a persistent project.
- **Choose your model.** Connect supported model providers or a compatible custom gateway.
- **Review the evidence.** Inspect the code, execution records, and provenance available for a result.

Projects and artifacts are stored locally. Model requests and external tools may send relevant content to the services you configure. [Read about data and permissions](https://aipoch.com/docs/settings/permissions-runtimes/).

## Start with a research question

Bring your own papers or dataset, define the task, and specify how the result should be checked.

| Try a task | Ask for outputs you can review |
| --- | --- |
| Reproduce an analysis from a paper | Analysis code, regenerated figures, and a comparison with the reported results. |
| Compare evidence across several papers | A source-linked table of methods, findings, and limitations. |
| Analyze a research dataset | A Notebook, result tables, figures, and an explanation of the methods used. |

## Explore the AIPOCH ecosystem

Already using a compatible AI agent? Start with **Medical Research Agent Skills**. For project management, executable analysis, file previews, and result inspection in one workspace, use **AIPOCH Open-Science**.

| Project | What it provides |

Read how [AIPOCH Open-Science records artifact provenance](https://aipoch.com/docs/workspace/notebook-provenance/) to help researchers inspect the code and execution evidence behind generated results. Researchers remain responsible for reviewing methods and validating scientific results.
